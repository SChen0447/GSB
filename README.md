# 灵犀看板 · 智能任务拖拽工作台

一个现代化、响应式的个人任务看板 Web 应用。用户可以通过拖拽在不同状态列之间移动任务卡片，支持添加、编辑、删除任务，并提供数据统计、实时搜索、主题切换和数据导出功能。

## 技术栈

- **框架**: React 18 (函数组件 + Hooks)
- **语言**: TypeScript (严格模式)
- **构建工具**: Vite
- **样式**: TailwindCSS
- **状态管理**: Zustand
- **拖拽库**: @dnd-kit
- **日期处理**: date-fns
- **图标**: lucide-react

## 功能特性

### 看板列结构
- 三列固定标题：待处理 (Todo)、进行中 (In Progress)、已完成 (Done)
- 支持将卡片从一列拖拽到另一列
- 拖拽时显示占位符和视觉反馈

### 任务卡片
- 显示标题、优先级、截止日期、描述
- 悬停时卡片上浮并加深阴影
- 支持编辑和删除（带确认对话框）
- 过期截止日期显示为红色

### 添加/编辑任务
- 表单可展开/收起
- 字段验证：标题必填、描述最多200字符、截止日期不能早于今天
- 编辑时可修改任务状态

### 统计面板
- 显示总任务数、各状态任务数、高优先级任务数
- 实时更新

### 搜索功能
- 实时过滤任务卡片
- 不区分大小写

### 主题切换
- 亮色/暗色主题切换
- 平滑过渡动画
- 保存到 localStorage

### 数据导出
- 导出为 JSON 文件
- 文件名包含时间戳

### 本地存储
- 自动保存所有变更
- 页面加载时恢复数据

## 项目结构

```
src/
├── components/
│   ├── Board.tsx       # 主看板组件（拖拽容器）
│   ├── Column.tsx      # 列组件
│   ├── ConfirmModal.tsx # 确认对话框
│   ├── StatsPanel.tsx  # 统计面板
│   ├── TaskCard.tsx    # 任务卡片
│   └── TaskForm.tsx    # 任务表单
├── store/
│   └── taskStore.ts    # Zustand 状态管理
├── types.ts            # TypeScript 类型定义
├── App.tsx             # 应用主组件
├── main.tsx            # 入口文件
└── index.css           # 全局样式
```

## 响应式设计

- 桌面端：三列横向布局，支持拖拽
- 移动端（宽度 < 640px）：三列垂直排列，禁用拖拽，显示提示信息
